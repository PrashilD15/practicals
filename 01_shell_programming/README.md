# Practical 1: Shell Programming (Address Book)

Interactive shell script providing options to create, view, insert, search, and delete records stored in a text file.

## Execution

```bash
chmod +x address_book.sh
./address_book.sh
```

## Notes & Viva

- Shebang (`#!/bin/bash`): Specifies the interpreter used to execute the script.
- grep options:
  - `-i`: case-insensitive search
  - `-v`: inverts match (used for deletion)
