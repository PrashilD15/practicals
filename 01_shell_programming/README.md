# Practical 1: Shell Programming (Address Book)

## Description / वर्णन
Interactive shell script providing options to create, view, insert, search, and delete records stored in a plain text database.

## How to Execute / Run (कसे चालवायचे):

```bash
chmod +x address_book.sh
./address_book.sh
```

## Viva Questions & Key Concepts / तोंडी परीक्षेसाठी महत्त्वाचे मुद्दे:
- **Shebang (#!/bin/bash): Tells the kernel which interpreter to use to execute the script commands.**\n- **grep options: -i performs case-insensitive search; -v selects non-matching lines (used for record deletion).**
